# 金融交易合成样例

固定种子 `20261116`，接口有效版本 `synthetic-small-v3-undirected-v1`。26 个稳定账户、12 个已观测快照和单独的 S13 回放观测。2026-01-01 10:00 +08:00 起，每个快照为 10 分钟左闭右开区间。

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 版本、种子、时间戳单位、观察截止及快照元信息 |
| `accounts.json` | 账户 ID、标签和固定显示坐标；坐标不参与查询 |
| `observed.json` | S01—S12 的实际存在账户集合，不保存交互 |
| `replay.json` | S13 的账户集合；只有主动观测接口读取 |
| `S01.csv`—`S12.csv` | 对应已观测快照的无向逐笔交互，固定 u,v,t 三列 |
| `S13.csv` | 后续交互，只有主动观测接口读取 |
| `scenarios.json` | 预测示例权重与数据构造参考；历史挖掘和 SLADE 均不读取场景注释 |

在 `demo/` 下运行 `uv run --directory backend python -m scripts.generate_sample` 可重建 13 个 CSV 和 5 个配置 JSON。生成器独立于前端原型，不依赖浏览器或 `demo-ui` 脚本。

每个 CSV 的表头为 `u,v,t`，数据行例如 `a-001,a-002,1767232805`。`u、v` 为源／目标账户，`t` 为 Unix 秒时间戳；当前样例使用整数秒，读取支持小数秒。UTF-8 编码，英文逗号分隔。同一时刻按文件顺序稳定处理，重复行完整保留，不需要交易 ID。金额、资产和首位数字字段已移除。完整数据契约见 [图数据结构](../README.md)。

S12 有 52 条无向边，共累计 183 次交互。默认五账户社区的结构密度为 1。每对账户只贡献一条结构边，交易次数按逐笔事件累加。

历史聚合接口合并所选 S01—S11 闭区间内的账户和交互，保留孤立账户，按无序节点对累计次数。结构统计和 core number 在聚合图上重新计算。

时间证据固定选中结构的账户集合，逐快照统计实际内部连接和交易次数；成员全部缺席时返回 `status=absent` 和空值，存在但没有内部交易时返回零。模式成员由算法在 S01—S11 全历史区间计算，结构参考统计来自 S11；拖动区间只改变聚合图与时间证据选区，不重新挖掘。

历史周期、持久和爆发分别运行 TD＋FT/AC、ONCE 和 MBC-B；逐快照投影保留孤立位置，度数按不同邻居计数。异常模块使用 SLADE：S01—S11 的 4,263 笔逐笔交互用于训练，S12 的 183 笔用于固定参数检测，输入只包含 `u、v、t`，不使用场景注释。预测使用示例权重并在全部群内候选上归一化，不读取 S13。S13 的“观测”仍是合成数据，实际份额由其中的交易次数统计。

## v2 历史结构信号

生成器在背景交易上添加以下账户间的逐笔合成交易，成员仍由论文算法计算，不从场景注释读取。当前默认参数采用 [共享配置](../../config/README.md) 中验证过的严格非空值，交易数据不随参数调整改变。

| 信号 | 数据构造 | 默认查询实际输出 |
| --- | --- | --- |
| 周期与持久 | `{a-001,a-002,a-007,a-008,a-013}` 在 S01、S04、S07、S10 形成完全图，其余时片保留背景连接 | 周期 `k=4,epsilon=1`：序列 `10010010010`，周期 3、重复 3 次；持久 `k=4`：形成于 S01，固定窗口起点后成员稳定至 S06，持续 5 个时间步 |
| 爆发 | `{a-014,a-015,a-016,a-020,a-021,a-022}` 在 S07—S09 连续形成完全图，其余时片保留背景连接 | `l=3,delta=5`：6 个成员，各成员 MSD 为 5，见证区间 S07—S09 |

新增边按逐笔交互生成时间和次数，使用独立随机流，原有背景交互和账户布局均保留。两组账户集合用于可复现的数据构造，并不是接口固定返回值，也不要求构成整图划分。持久与周期方法可以发现同一成员集合，二者时间定义不同。

v2 增加上述历史结构信号；v3 将交互精简为 `u、v、t`，完整保留 v2 的账户、逐笔端点、时间与重复次数，并已训练匹配版本的 SLADE 模型。当前物理存储进一步改为逐快照 CSV，逻辑交互、顺序与模型指纹保持相同，继续使用 v3 和已有 GPU 权重。生成器保留旧随机流的抽样步数以复现相同交互。版本参与缓存和结构哈希；过严参数仍返回空结果，不执行结果回退。

为覆盖无观测交互场景，`a-026` 在 S13 没有出向交易。通过当前局部 core 查询 q=a-026、k=0 选择包含它的结构，以它为源账户独立调用后端观测接口时，会返回 `no_interactions`，不生成均匀真实份额。
