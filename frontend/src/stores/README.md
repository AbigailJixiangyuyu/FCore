# 共享交互状态

`workbench.js` 保存数据集选择、时间位置 `timeIndex`、历史起止 `historyStartIndex` 和 `historyEndIndex`、各阶段参数、结构选择和 SLADE 定位账户。初始位于 S12，历史范围为 S01—S11。

历史拖动在 01 内预览，松手后通过 `selectHistoryRange` 一次保存两端和时间位置。历史聚合请求使用数据版本和已提交的范围。进入 S12、S13 时记住历史两端，从 02 返回历史时恢复。

02 的挖掘起止属于各方法的参数草稿。提交时保存两端，并将 01 定位到所选区间。此后 01 的拖动只更新展示范围，05 保留已提交的挖掘范围。

03 初始展示全图，得到结果后展示查询或预测社区。点击 04 账户返回 S12 定位。在社区视图中，社区外的账户可单独查看。布局坐标与版本缓存由专用 composable 管理。

初始状态与数据集切换均读取 `demo/config/query-defaults.json`，前后端共用。历史每个方法的草稿与已提交参数各自复制，编辑互不影响；当前局部 core 按数据集初始化。默认参数已按数据集验证，参数编辑和空结果不触发自动回退。

接口结果与加载状态由 TanStack Vue Query 管理。每次提交生成新的 `analysisRunId`，用它启用请求并区分缓存。切换算法或阶段时清除提交状态和图中定位，保留参数草稿。

`futureDraft` 和 `futureSubmitted` 分别保存未来查询的 q、k 和阈值草稿与提交值，`predictionModel` 保存 Zebra／UnderGS 选择，默认 Zebra。点击图中节点可填写 q 草稿。点击「开始预测」后加载结果。
