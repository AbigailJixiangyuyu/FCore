# 时域核查询

时域核查询接收一段包含首尾的历史范围和正整数 `k`。在范围内的各个连续子区间中，将出现过的节点对合成无向简单图，并求每个节点至少有 `k` 个不同邻居的最大诱导子图。每个结果保留完整的核及其最紧区间，允许有多个连通分量。

## 快照与最紧区间

快照在查询范围内的顺序是算法使用的时间。同一快照内同一节点对的多次交互合成一条时间边，同一对节点跨快照出现时分别保留。给定一个核，第一条内部边和最后一条内部边所在的快照是它的最紧区间。相同最紧区间的结果合并，成员相同而最紧区间不同的结果分别返回。界面边数按最紧区间内的节点对计数，交互次数依然累计原始记录。

## OTCD

`mine_temporal_cores` 用若干快照的边集作为内存输入。它按起点递增、终点递减遍历子区间。从一个覆盖当前窗口的已计算核中截去窗口外的边，再按不同邻居数剥离度低于 `k` 的节点。据最紧区间应用论文的 PoR、PoU 和 PoL 规则标记可跳过的窗口。返回结果依次按区间长度、成员数、起点升序排列。[Scalable Time-Range k-Core Query on Temporal Graphs，第 3–4 节](https://www.vldb.org/pvldb/vol16/p1168-zhong.pdf#page=4)

在 EmailDept3 的 S01—S11 以 `k=7` 查询得到 55 个核，在 S07—S11 得到 10 个。其中 S07—S08 对应 27 个节点、140 条边，S10—S11 对应 18 个节点、79 条边。测试还用独立计算逐一枚举小图的所有子区间，核对成员及最紧区间。
