# 持久社区：ONCE 实现

对应 Zhou 等人的 *Effective Durable Community Search in Large Temporal Graph*，PVLDB 19(2), 127-140, 2025，DOI：[10.14778/3773749.3773753](https://doi.org/10.14778/3773749.3773753)。实现依据定义 2.1-2.5、Problem 1、Algorithm 1 (ONCE) 和引理 4.4；本地论文见 `参考论文/持久社区/持久社区.pdf`。

## 输入与输出

```python
mine_durable(snapshots, account="a-001", k=4) -> PatternResult | None
```

输入是按时间排列的无向、无权、简单快照邻接表，类型为 `TemporalSnapshots`。公共适配层按节点对建立邻接，按所选区间的账户并集补齐缺席账户，并保留空快照。`k` 必须为正整数。

函数只读取传入的快照，搜索范围为本次提交的区间，默认使用 S01—S11。稳定截止位置至多为本次查询区间的终点。

有结果时返回 `PatternResult(members, evidence)`。`members` 是排序后的账户元组。`evidence` 包含：

| 字段 | 含义 |
| --- | --- |
| `formation_start` | 累计投影窗口起点 a |
| `formation_end` | 累计投影窗口当前终点 b |
| `stable_end` | 固定 a，向右延长终点后成员最后保持不变的位置 r |
| `duration` | r-b，以输入时间步的差值计量 |
| `member_count_series` | 固定起点 a，按顺序记录终点从 a 延伸到最后一个快照时的社区成员数。对应窗口没有社区时记为 0 |

位置全部从 0 开始，窗口两端包含。Sxx 映射和实际时间单位换算由服务层负责。不存在有效社区时返回 `None`。没有快照、q 在所选区间中不存在或 k 非正整数时抛出 `ValueError`。

## 计算过程

对每个子窗口 `[a,b]`，将原始快照内的边取并集，得到论文定义 2.1 的投影图。对其计算 k-core，只保留包含 q 的连通分量，记作 C[a,b]。固定 a 时，窗口延长只增加边，C[a,b] 的成员只能扩张，因此 ONCE 能二分寻找最大的 r，使 C[a,r]=C[a,b]。最终返回 duration 最大的非空社区。

实现对每个投影图的社区缓存一次，并复用现有静态 core 查询。T 个快照最多有 T(T+1)/2 次 core 计算，当前 11 帧仅 66 次。复用的静态 core 实现含 O(n²) 的最小度扫描，因此总时间为 O(T²(n²+m)+T² log T)，m 是区间边并集规模。没有引入 ASF/ATG 索引；后续可在同一结果契约下接入论文的加速算法。

## 明确的边界约定

- 持续时间采用论文示例及引理 4.4 的口径：`[2,3]`、`[2,4]`、`[2,5]` 的成员相同，`[2,6]` 发生变化，持续时间为 5-3=2。稳定位置区间 `[b,r]` 具有 duration+1 个位置，不能将其数量与 duration 混用。原文定义 2.4 的不等号存在一位差疑点，此处按示例处理。
- r 最多到输入的最后一个位置；不向观察范围之后延伸，也不将无后续扩张解释成无限持续时间。
- 空集合不参与结果竞争。若有效非空社区的最优持续时间为 0，仍返回它。这按 Problem 1 的优化定义补齐了 Algorithm 1 中以空集时长 0 初始化、只在严格更大时更新所遗漏的情况。
- 多个最优社区按 duration 降序、a 升序、b 升序、members 字典序选一个。并列规则是工程约定，原文未完整规定。
- 稳定性比较成员集合；内部边变化不影响成员不变的判断，其他连通分量变化也不影响 q 所在社区。
