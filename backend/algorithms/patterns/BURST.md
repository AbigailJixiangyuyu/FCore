# 爆发核算法接入说明

依据 Qin et al., *Mining Bursting Core in Large Temporal Graphs*, PVLDB 15(13):
3911–3923, 2022，定义 3–5、算法 1 和实验中的 MBC-B 基线。
[发表版本](https://www.vldb.org/pvldb/vol15/p3911-wang.pdf)，
[DOI](https://doi.org/10.14778/3565838.3565845)。

## 方法与输入

`mine_burst(snapshots, l=3, delta=3.0)` 使用论文 MBC 剥离框架，并精确枚举
MSD 的所有连续区间；方法标识为 `mbc-exact-segments-v1`。它求解原论文的
`(l, δ)-MBC`，不使用 MBC+ 的增量凸包缓存，不使用人工场景注释。

输入为按时间顺序排列的无向简单图，类型为
`tuple[dict[str, frozenset[str]], ...]`。公共数据适配层负责无向投影、去重、
去除自环，并让所有快照共享所选区间的账户并集。缺席账户作为孤立账户保留。
空快照仍占一个时间位置。函数只读输入，不加载文件、打印结果或保留跨请求状态。

- `l` 为严格整数，范围为 `2 ≤ l ≤ T`，表示连续区间的最小快照数量。
- `delta` 为正有限数，表示该区间的平均内部度阈值，不是 0–1 图密度。
- 纯算法默认 `l=3、delta=3.0` 沿用论文实验设置。工作台可提交查询节点 q，服务层仅在原最大爆发核包含 q 时返回该结果，分析面板使用 q 的度序列和见证区间。
- 参数非法时抛出 `ValueError`；HTTP 层将它转换为参数错误响应。

算法使用提交区间的逐快照序列，最小长度 `l` 不能超过区间包含的快照数。各成员的见证区间都在本次挖掘范围内。

## 定义与执行

对候选账户集合 C 和账户 u，先计算逐快照内部度数 `d_t(u,C)`，然后求：

```text
MSD_l(u,C) = max(sum(d_t(u,C), t=a..b) / (b-a+1))
             over all contiguous [a,b] with b-a+1 >= l
```

结果中每个账户均满足 `MSD_l(u,C) ≥ delta`，且结果在账户集合包含关系上极大。
具体步骤为：

1. 在全历史无向并集上提取 `ceil(delta)`-core，进行必要条件预筛选。
2. 计算候选集合内每个账户的完整度序列及最大区间平均度。
3. 删除未满足阈值的账户，更新其存活邻居的逐快照度数并重新检查，直到稳定。
4. 基于最终集合重新计算每个成员的见证区间，返回唯一极大结果。

候选集合缩小时，任一账户的各区间平均度都不会增加，因此已删除账户不可能
属于任何合法结果。终止时所有存活账户均满足定义，得到唯一最大合法集合。
结果可以不连通；不同账户可以有不同见证区间。模块不会拆分连通分量，
也不会捏造一个全体成员共享的爆发窗口。

内部以 `Fraction` 表示阈值；浮点输入先按 `str(delta)` 的十进制值转换。
区间平均度和阈值全部采用整数交叉相乘比较，不使用浮点容差。相同平均度
选择最短区间，再选择最早起点。

## 输出与复杂度

无合法非空结果时返回 `None`；否则返回公共 `PatternResult`：

```python
PatternResult(
    members=("a", "b", ...),  # 账户 ID 排序
    evidence={
        "nodes": [
            {
                "account": "a",
                "degree_sequence": [...],
                "numerator": 9,       # 见证区间的度数之和，不约分
                "denominator": 3,     # 见证区间长度
                "witness_start": 2,   # 0-based，含端点
                "witness_end": 4,
            },
        ],
    },
)
```

证据仅含 JSON 可序列化值。快照 ID、显示小数及 HTTP 元信息由业务层补充。

令 n 为账户数、m 为全历史无向并集边数、M 为逐快照无向边数之和、T 为快照数。
时间复杂度为 `O(M + (n+m)T² + n log n)`，最后一项来自确定性的账户排序；
输入之外的辅助空间为 `O(nT+m)`。
当前 `T=11、l=3` 时，每次 MSD 检查仅需枚举 45 个区间。
