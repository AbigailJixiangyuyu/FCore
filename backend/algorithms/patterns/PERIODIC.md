# 周期社区：TD + FT/AC 复现

来源：Yu Chen 等，*Periodic Community Search in Temporal Graphs: Time Series-based Methods*，PACMMOD 4(3)，2026，[DOI: 10.1145/3802099](https://doi.org/10.1145/3802099)。原文位于 `参考论文/周期社区/周期社区.pdf`。

本模块实现论文算法 1、2 的 TD 候选生成，以及第 3.2 节的 FT + AC 周期检测。方法标识为 `lpc-td-ftac-v1`，边界约定版本为 `td-ftac-boundaries-v1`。这是带显式工程约定的论文流程复现，不是作者代码逐行移植，也不承诺 LPC 顶点子集优化的全局最优。

## 输入与输出

```python
mine_periodic(snapshots, account="a-001", k=4, epsilon=0.2)
```

- `snapshots` 为按时间排序的 `tuple[dict[str, frozenset[str]], ...]`。每个快照是无向简单图，使用所选区间的账户并集，缺席账户保留为空邻居。完整保留空时片，输入不被修改。
- `k` 为正整数，`epsilon` 为 `[0,1]` 内有限数值。HTTP、数据版本、账户存在性和 Sxx 编号校验属于服务层。
- 返回 `PatternResult(members, evidence)` 或 `None`；一个查询返回一个确定性选中的结果。
- `evidence` 包含实际 `kcore_series`、最佳 `period`、完整块数 `frequency`、`start_index`、`end_index`，以及全部极大周期段和频谱筛选信息。时间位置从 0 开始，首尾均包含。
- 服务层传入提交的挖掘区间。周期检测在区间内重新计算，合法无解时返回 `None`。

## 固定复现约定

### TD 候选

1. 以两个不同时间点为初始必选集合，按相同前缀连接同长度时间集合，每次增加一个必选时间；非空共同核去重为候选。
2. `Compute` 在所有必选快照之间联合传播低度删除，q 被删除即无结果。采用定义 3.1、4.1 和算法 2 的度约束，**不额外加入连通性过滤**。原文其他段落使用 connected/BFS，存在口径不一致，未把另一种定义静默混入此实现。
3. 每个候选的二值序列从全部原始快照重新计算，不把时间掩码的并集当作事实序列。

### 频谱与 AC

1. 使用未归一化 DFT 的非 DC 正半谱，即频率整数 `1..floor(T/2)`，保留偶数长度的 Nyquist 项。纯 Python 计算并复用 DFT 系数，无额外依赖。
2. 每个二值序列独立从 `SHA256("20261116:" + binary_series)` 的大端整数派生随机种子；每次置乱都从该原序列重新复制，总共 100 次，记录每次非 DC 正半谱的最大功率。
3. 阈值忠实采用原文 **100 个值中的第 99 大**，即降序排序下标 98。它与通常的 99% 上分位数不同，**不把它表述为统计学 99% 显著性检验**。原文两种文字不一致，本模块明确选择字面次序。
4. 功率必须严格大于阈值；相对误差 `1e-10`、绝对误差 `1e-12` 内视为相等，仅用于防止机器误差制造显著峰。
5. 原文 `[T/f, T/(f-1))` 按向外离散化转为 `floor(T/f)..ceil(T/(f-1))-1`，再裁剪至 `1..floor(T/2)`；`f=1` 跳过，因为没有可容纳至少两个完整块的周期。向外取整是显式工程边界解释，例如论文序列 `1001001001` 的主频为 3，须允许整数周期 3 进入候选。
6. 使用循环 AC。在每个离散候选区间内比较相邻值；等高平台作为整体，平台高于现有左右邻居时保留最左位置。单点区间和整个区间等高时取最左位置，跨区间得到的周期去重。
7. 常量 0、常量 1、少于四个时片的序列均无有效非 DC 周期候选。常量 1 按抽象重复定义可以有周期，但此处忠实采用 FT/AC 流程，不增加 DC 或周期 1 回退。正半谱实际得到的候选周期至少为 2。

### 极大周期段与选优

1. 枚举每个候选周期的全部起始相位，只使用完整等长块，不足一个周期的尾部不计入段。
2. 每个新块必须与此前所有块两两满足 Jaccard 阈值；使用整数计数和十进制阈值的有理数比较，避免阈值边缘浮点偏差。
3. Jaccard 空并集约定为 1，但整个周期段至少含一个 1。`epsilon=0` 不被替换为更高阈值，可接受零重叠块；全零段仍不算周期出现。
4. 同一周期、同一相位下，删除被其他合格段严格包含的段；不同相位分别保留。评分只取单个极大段的最大完整块数 F，不把不同段的次数相加。
5. 取 TD 候选中最高 F，移除同分结果中的严格成员子集。多个不可比结果并列时按成员数降序、账户 ID 字典序选一个；同一结果的最佳证据按时间起点、周期长度、终点升序选择。

## 已知限制

TD 候选不覆盖全部顶点子集，不能由候选内部的正确评分推出原 LPC 定义的全局最优。例如 `k=2,T=9,q=a,epsilon=1`：在 `100100100` 的 1 时片放置四点完全图，其余 `110101100` 的 1 时片放置四点环，剩余时片为空。三点集合 `{a,b,c}` 的序列为 `100100100`，按等长重复定义可重复三次；四点集合 `{a,b,c,d}` 的序列为 `110101100`，其最高完整重复次数只有二。所有非空共同核却都是四点集合，TD 不会产生该三点集合。本模块的候选空间遵循论文 TD，不扩展为全顶点子集搜索。

`synthetic-small-v2` 在 S01、S04、S07、S10 添加五账户 4-core 的实际交易，默认 `q=a-001,k=4,epsilon=0.2` 可计算出 5 个账户，真实序列 `10010010010`、周期 3／重复 3 次。v1 的历史 4-core 不足，曾在默认条件下返回空。样例修改仅涉及交易数据，不改变本算法；无周期候选时仍返回空，不读取 `scenarios.json` 的预置成员替代输出。
